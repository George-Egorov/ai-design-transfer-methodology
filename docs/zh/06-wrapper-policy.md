# 包装器

包装器是具有明确作用的真实 Figma 框架或组件。它不是额外标签，也不是写在图层名称中的说明。

## 保留包装器，如果它

- 将一起响应式变化的元素组合在一起；
- 创建列表、网格、表面或裁剪区域；
- 负责背景或交互区域；
- 定义模态窗口、状态或可导出插图。

```text
hero-copy
  hero-title
  hero-subtitle
```

## 删除包装器，如果它

- 只是因为图层被同时选中才存在；
- 只有一个子图层且没有结构作用；
- 改变坐标但不增加含义；
- 是资源之外的普通 `GROUP` 或 `Frame 53`。

内容流使用 Figma 原生布局。`[decor]` 只标记视觉图层，不能为自由内容容器提供理由。真正不透明的视觉可以使用 `[decor] [asset]`。

## 保持树稳定

不同宽度可以改变设置，但有意义的包装器及其在图层树中的位置应保持可识别。只在一个宽度中存在的包装器需要记录结构原因。
